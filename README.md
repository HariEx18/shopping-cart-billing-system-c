# Shopping Cart Billing System in C

A simple command-line Shopping Cart and Billing System developed using C programming.

This project allows users to enter an item name, price, and quantity, then generates a formatted purchase bill and calculates the total amount automatically.

## Features

* Accepts item name as input
* Accepts item price and quantity
* Calculates total bill amount
* Generates a clean and formatted purchase receipt
* Demonstrates basic string handling and user input processing

## Concepts Used

* Variables and Data Types
* User Input (`scanf`, `fgets`)
* String Manipulation (`string.h`)
* Arithmetic Operations
* Formatted Output (`printf`)
* Basic Program Structure in C

## Sample Output

```text
=================================
         PURCHASE BILL
=================================

Item     : Chicken Burger
Price    : $7.00
Quantity : 2

---------------------------------

Total    : $14.00

=================================
```
